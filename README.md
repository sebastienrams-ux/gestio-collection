# Ma Bibliothèque

Appli web (installable sur téléphone) pour gérer une collection de BD, comics, livres et jeux de rôle.

- **Manques** : les tomes qui manquent dans chaque série, et la recherche « est-ce que je l'ai ? » pour les marchés et l'occasion. Fonctionne hors ligne.
- **Collection** : toutes les séries, avec vignettes de couverture (Google Books, Open Library).
- **Ajouter** : dictée ou saisie « Série tome N », puis choix de la bonne édition parmi les propositions des bases.
- **Réglages** : import / export de la collection (fichier JSON).

La collection est enregistrée uniquement dans le navigateur de l'appareil : ce dépôt ne contient que le code.
